## 10. Ошибки, найденные при исправлении (вне отчёта)

- Celery-воркер слушал только очередь `etl`: сбор WB/Ozon, конкурентов и automation не выполнялся.
- Роли из ClickHouse (`Enum8`) приходили строкой — аутентификация пользователей падала.
- Создание организаций, участников и аккаунтов магазинов падало (та же ошибка, что C-03).
- Остатки WB отправлялись в read-only Statistics API; upsert себестоимости падал; поиск PIM ссылался на несуществующий алиас.
- Правило `turnover_alert` ломало весь прогон automation.
- `service_readiness{clickhouse}` всегда был 0 (нет прав на `system.disks`) — алерт срабатывал бы постоянно.
- Редирект HTTP→HTTPS вёл на порт контейнера 8443; после пересоздания backend прокси отдавал 502.
- Rate limiter отдавал 500 вместо 429 и имел один бакет на всех клиентов.
- UI: введённый ключ не применялся до перезагрузки; ползунки ставок отправляли запрос на каждый пиксель (дубликаты правил); `make frontend` удалял каталог вне репозитория.
- Расширение: XSS через `innerHTML`, ключ в синхронизируемом хранилище, несовместимый с API формат цен.
