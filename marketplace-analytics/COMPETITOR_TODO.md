## Фичи, которых нет у нас (но есть у конкурентов)

### 1. Внешняя аналитика конкурентов ⭐
Самая главная фича. Все SaaS показывают не только «свои» продажи, а
продажи, выручку, остатки, цены **любого товара/продавца/бренда**
на маркетплейсе. Сбор из открытых данных (карточки товаров, поисковая выдача).

**Что делать:** парсить выдачу WB/Ozon по категориям и поисковым запросам,
сохранять цены, остатки, позиции — денормализованно и с историей.

- MPStats: внешняя аналитика WB, Ozon, Я.Маркет
- LikeStats: внешняя аналитика + анализ категорий, брендов, продавцов
- MarketGuru: анализ ниш, артикулов, конкурентов

### 2. Поиск ниш и категорий
«Что продавать»: анализ спроса, конкуренции, сезонности в разрезе категорий.
Помогает новичкам выбрать товар, опытным — найти точку роста.

**Что делать:** агрегировать данные из п.1, строить отчёты по категориям:
динамика выручки, доля топ-продавцов,饱和度 ниши, потенциал входа.

### 3. SEO-инструменты
Частотность поисковых запросов, позиции товара в выдаче по ключевым словам,
кластеризация запросов, рекомендации по оптимизации карточки.

**Что делать:** нужен сбор данных поисковой выдачи (какие товары показываются
по запросу, на какой позиции, как меняется со временем).

- LikeStats: кластеры ключевых слов, проверка SEO
- MarketGuru: SEO-оптимизатор, поисковые запросы
- MPStats: поисковые запросы, видимость в выдаче

### 4. Автоматизация рекламы
- **Биддер** — автоуправление ставками в рекламных кабинетах WB/Ozon.
  MarketGuru обещает -35% ДРР.
- **Репрайсер** — автоматическое изменение цены (для поддержания позиции
  или маржинальности).
- **A/B-тестирование фото** — показ разных вариантов карточки, замер конверсии.

**Что делать:** интеграция с API рекламных кабинетов WB/Ozon. Репрайсер —
только через API маркетплейса (не внешний парсинг).

- MarketGuru: биддер, репрайсер, A/B-тесты
- MPStats: биддер для WB
- LikeStats: биддер с кластерами

### 5. AI-функции
Генеративный AI для селлеров:
- написание SEO-описаний карточек
- генерация инфографики / видео
- автоответы на отзывы (нейросетью)
- анализ конкурентов текстом
- «Оракул» у MarketGuru как единый AI-мозг

**Что делать:** обёртка над API LLM (GigaChat API, YandexGPT, либо локальная
модель). Не критично для MVP, но продаёт подписку.

- MarketGuru: Guru AI, Oracle, автоответы
- LikeStats: копирайтер GPT
- MPStats: AI-агент для консультаций

### 6. Юнит-экономика и финансы
Учёт себестоимости товара, всех косвенных расходов (аренда, ЗП, налоги,
эквайринг, логистика) — расчёт **реальной** прибыли по каждому SKU.
ABC-XYZ анализ, ДРР по рекламным кампаниям.

**Что делать:** добавить ручной ввод себестоимости/расходов (через UI),
автораспределение по дням, отчёты по прибыльности.

- SellerData: лучший в этом — полный учёт расходов, амортизация, налоги
- MarketGuru: ABC-XYZ, финансовая аналитика, себестоимость
- MPStats: отчёты по выкупам с учётом возвратов

### 7. Планирование поставок
Прогноз даты «стопа» товара, расчёт объёма следующей партии,
учёт транзита и остатков на своих складах, рекомендация по дням поставки.

**Что делать:** нужна модель прогноза продаж (хотя бы скользящее среднее),
UI для ввода транзита и собственных остатков.

- SellerData: автоматические уведомления о необходимости заказа
- MarketGuru: контроль остатков

### 8. Браузерный плагин
Расширение для Chrome — данные о товаре (продажи, выручка, цена, позиция)
прямо на странице WB/Ozon при просмотре карточки товара.

**Что делать:** Chrome extension с вызовом своего API. Небольшой объём работы,
но сильный wow-эффект. Есть у MPStats и LikeStats.

### 9. Коллаборация
Multi-user, ролевая модель (админ, менеджер, аналитик), командные рабочие
пространства. Позволяет продавать «на рабочее место».

**Что делать:** добавить пользователей в backend (сейчас один API key),
разграничение прав, аудит действий.

### 10. Enterprise
Кастомные отчёты, SLA, выделенные ресурсы, мульти-аккаунты, интеграции с
внутренними системами клиента, whitepaper / security docs.

**Что делать:** не раньше, чем появится платящий enterprise-клиент.

- MarketGuru: ISO 27001, 152-ФЗ, мульти-аккаунты
- MPStats: Enterprise-решения, Data-отчёты

### 11. Поддержка большего числа маркетплейсов
- Яндекс Маркет (уже есть API, внешней аналитики)
- Avito (LikeStats уже умеет)
- Ozon уже есть (но нужна внешняя аналитика по аналогии с WB)

## Что уже есть у нас (наши преимущества)

- Self-hosted / open-source — данные не уходят на сторону
- ClickHouse — скорость аналитики на больших объёмах
- Свой REST API — полный контроль интеграций
- Celery pipeline — асинхронные сборщики с блокировками и водяными знаками
- Движок правил автоматизации — реакции на события по заданным условиям
- Prometheus-метрики — мониторинг пайплайна, алерты
- Миграционная система для ClickHouse с откатами
- Инкрементальный сбор с защитой от дубликатов (ReplacingMergeTree + FINAL)
