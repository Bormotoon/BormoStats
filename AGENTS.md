# Правила работы с проектом BormoStats

`BormoStats` — продакшен-система аналитики маркетплейсов. Остановка продакшена недопустима. См. также общие правила пространства [`../AGENTS.md`](../AGENTS.md) и session memory в [`.agents/AGENTS.md`](.agents/AGENTS.md).

## Обязательное использование OpenViking (`openviking`, `viking://`)

1. **Поиск до сканирования:** перед началом задачи, изучением незнакомых модулей или рефакторингом проверьте `viking://resources/` и `viking://user/memories/` через слои L0 (abstract) и L1 (overview). Вызывайте `read_file` точечно по найденным путям.
2. **Передача URI субагентам:** при запуске субагентов передавайте им конкретные `viking://resources/...` URI вместо сканирования целых директорий.
3. **Фиксация решений:** по завершении нетривиальной задачи или архитектурного изменения сохраните краткую выжимку решений (и отклонённых альтернатив) в `viking://resources/architecture_decisions`.
4. **Нулевые ПД (152-ФЗ):** категорически запрещено сохранять в `viking://` персональные данные (ФИО, email, телефоны, IP-адреса, секреты и реальные данные пользователей).

## Обязательное использование Skill-Router (`skill-router`)

Библиотека навыков (`~/.agents/skills/`) подключена через MCP-сервер `skill-router` (`on-demand`). Для любых предметных задач (UI/UX, `unslop` / `unslop-ui`, доступность, SEO, контент, AI-медиа и др.) **запрещено импровизировать**, если есть готовый runbook:

1. Вызовите `search_skills(query="<задача или ключевые слова>", limit=5)` (или `list_skills(category="...")`: `design-and-ui`, `seo`, `social-media`, `ai-media`, `all`).
2. Загрузите полный `SKILL.md` через `get_skill(name="<skill-name>")`.
3. Точно следуйте инструкциям, проверкам и ограничениям из загруженного навыка.
